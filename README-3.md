# 三者面談ナビ（高2本科 2026）導入手順

画面は GitHub Pages、データは学校の Google スプレッドシートに置きます。両者は Google Apps Script（GAS）でつなぎます。

| 置く場所 | ファイル | 中身 |
|---|---|---|
| GitHub | `index.html` | アプリの画面（生徒データは入っていません） |
| GitHub | `config.js` | GASのURLを書く設定ファイル（ここだけ編集します） |
| スプレッドシートのApps Script | `Code.gs` | サーバー（GitHubには上げなくてよい） |

**大事な注意：Excel・CSV（成績・進路結果・ベネッセのデータ）は絶対に GitHub に上げないでください。GitHub のリポジトリは公開されます。**


## 1. スプレッドシートを作る（学校アカウントで）

1. 学校の Google アカウントで Google ドライブを開き、「新規 → Google スプレッドシート」で新しいスプレッドシートを作ります。名前は「三者面談ナビ_高2_2026」など。
2. 共有するのは、学年の担任の先生だけにします（記入シートに評定などを入れてもらうため、編集者として共有）。


## 2. Googleフォームの回答をつなぐ

1. フォーム「三者面談前進路ガイダンス」を開き、「回答」タブ →「スプレッドシートにリンク」を押します。
2. 「既存のスプレッドシートを選択」で、1で作ったスプレッドシートを選びます。
3. スプレッドシートに「フォームの回答 1」というシートができます。このシートは編集しないでください。


## 3. GAS を入れて初期設定する

1. スプレッドシートのメニュー「拡張機能 → Apps Script」を開きます。
2. 最初からある `function myFunction() {…}` をすべて消し、`Code.gs` の中身をまるごと貼り付けて、保存（フロッピーのマーク）を押します。
3. スプレッドシートのタブに戻り、ページを再読み込みします。少し待つと、メニューに「三者面談ナビ」が出ます。
4. 「三者面談ナビ → ① 初期設定」を押します。
   - 初回は「承認が必要です」と出ます。「続行」を押し、自分のアカウントを選び、「詳細」→「（安全ではないページ）に移動」→「許可」と進みます。
   - もう一度「① 初期設定」を押します。
5. 「記入シート」と「面談メモ」ができ、**担任用パスコード**と**管理者用パスコード**が表示されます。メモしてください（あとでメニュー「パスコードを確認する」でも見られます）。
   - 担任用：学年の担任の先生に伝えます。
   - 管理者用：先輩の進路結果・指定校一覧を登録するときだけ使います。


## 4. GAS をウェブアプリとして公開する

1. Apps Script の画面右上「デプロイ → 新しいデプロイ」を押します。
2. 歯車マーク →「ウェブアプリ」を選びます。
3. 次のように設定して「デプロイ」を押します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**（「Google アカウントを持つ全員」や「明星学苑内の全員」だと、GitHub Pages から通信できません）
4. 表示された「ウェブアプリのURL」をコピーします。`https://script.google.com/macros/s/……/exec` の形です。
   - 途中に `/a/macros/edu.meisei.ac.jp` が入っている場合は、その部分を抜いた形にしてください。

「全員」にすると、URLを知っている人は誰でもGASに送信できる状態になります。データはパスコードで守っています。パスコードの入力ミスが30回続くと、10分間すべての受け付けを止めます。


## 5. GitHub に上げて公開する

1. GitHub で新しいリポジトリを作ります（例：`sansha-navi`）。
2. 「Add file → Upload files」で `index.html` と `config.js`（とこの `README.md`）を上げます。
3. `config.js` を開いて鉛筆マーク（編集）を押し、`API_URL: ''` の `''` の中に、4でコピーしたURLを貼り付けます。

   ```
   window.SANSHA_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/……/exec'
   };
   ```

   「Commit changes」で保存します。
4. 「Settings → Pages」で、Branch を `main`、フォルダを `/ (root)` にして「Save」を押します。
5. 1〜2分待つと、`https://（GitHubのユーザー名）.github.io/sansha-navi/` で開けるようになります。


## 6. 先輩の進路結果・指定校一覧を登録する（最初に1回、管理者が行う）

1. 5のURLを開き、**管理者用パスコード**でログインします。
2. 右上「データ読み込み」を押し、次の3つのExcelをまとめてドラッグします。
   - 2025年度進路合議・進学確認
   - 2014〜2023年度 進路結果
   - 指定校一覧（ご参考）
3. 読み込み結果を確かめ、「いま表示中の先輩データ・指定校をスプレッドシートに登録」を押します。

送るのは、学籍番号・担任・男女・出身校などの列を除いたデータだけです。登録すると、学年の先生全員の画面に反映されます。


## 7. 担任の先生がすること

1. スプレッドシートのメニュー「三者面談ナビ → ② フォームの氏名を記入シートに写す」を押します。フォームに回答した生徒の氏名が、記入シートに入ります（何度押しても重複しません）。
2. 記入シートに、組・番号・現在の評定平均を入れます。
3. 7月模試のGTZは、次のどちらかで入れます。
   - 記入シートに直接入れる（S1〜D3 のプルダウン）。
   - アプリの「データ読み込み」にベネッセの模試CSVをドラッグし、「7月GTZを記入シートに書き込む」を押す。組・番号が合う生徒の空欄だけに入ります。スプレッドシートに送るのは組・番号・GTZ・偏差値・文理だけで、氏名・生年月日などは送りません。
4. アプリで「データ読み込み → スプレッドシートから読み込み直す」を押すと、画面に反映されます。

面談中にアプリで入れた志望校・検討候補・面談シートの内容は、自動で「面談メモ」シートに保存されます。ほかのパソコンで開いても続きから使えます。


## Code.gs を直したとき

「デプロイ → デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」→「デプロイ」で更新します。この方法ならURLは変わりません。「新しいデプロイ」を作るとURLが変わるので、config.js も書き換えてください。


## うまく動かないとき

- ログイン画面で「サーバー（GAS）に接続できませんでした」と出る：4の「アクセスできるユーザー」が「全員」か、config.js のURLが `/exec` で終わっていて `/a/macros/…` を含まないかを確認します。
- 「全員」が選べない：学校の Google 管理者が外部公開を止めています。その場合は、画面をGASから配信する形に作り替えれば「明星学苑内の全員」のまま使えます。
- エラーの中身を知りたい：Apps Script 左の「実行数」に、失敗した記録とエラー文が出ます。


## 年度末・面談期間が終わったら

- メニュー「担任用パスコードを変更する」でパスコードを変えます。
- 記入シート・面談メモ・フォームの回答は、学校のルールに従って削除・保管します。
