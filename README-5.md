# 三者面談ナビ（高2本科 2026）導入手順

生徒の情報は前もって入れません。面談の場で、評定・7月模試・系統・受験方式などを選ぶと、先輩の進路結果と指定校一覧から参考資料が出ます。調べた内容は自動で「面談記録」に残り、担任の先生と八幡先生（管理者）で共有します。

パスコードはありません。学校のGoogleアカウントでログインしていて、共有スプレッドシートの「使える先生」シートで○が付いている先生だけが開けます。生徒のアカウントでは開けません。

| 置く場所 | ファイル | 役割 |
|---|---|---|
| GitHub | `app.js`・`app.css` | アプリの画面のプログラム（データは入っていません） |
| GitHub | `index.html` | 単独で開ける版（サンプル確認・ネットなしで使うとき用） |
| 共有スプレッドシートのApps Script | `Code.gs` | サーバー（GitHubには上げません） |
| 学校のGoogleドライブの資料フォルダ | 先輩の進路結果・指定校一覧のExcel | 参考資料のもと |

先生が開くのは、GitHubのURLではなく、手順4で出る**GASのウェブアプリのURL**です。

**Excel・CSVは絶対にGitHubに上げないでください。GitHubのリポジトリは公開されます。**


## 1. GitHubに上げる

1. GitHubで新しいリポジトリを作ります。例：`sansha-navi`。
2. 「Add file → Upload files」で `app.js`・`app.css`・`index.html`・`README.md` を上げます。
3. 「Settings → Pages」で Branch を `main`、フォルダを `/ (root)` にして「Save」します。
4. 1〜2分後、`https://（ユーザー名）.github.io/sansha-navi/` を開けることを確かめます。このURLは手順3で使います。

前の版の `config.js` は使いません。リポジトリに残っていたら削除してかまいません。


## 2. 資料フォルダを用意する（学校のGoogleドライブ）

1. 学校のGoogleドライブ（共有ドライブでも可）に、資料用のフォルダを作ります。
2. 次のExcelを入れます。ファイル名は自由です。
   - 2025年度進路合議・進学確認
   - 2014〜2023年度 進路結果
   - 指定校一覧（ご参考）


## 3. 共有スプレッドシートを作り、GASを入れる

1. 学校アカウントで、新しいGoogleスプレッドシートを作ります。例：「三者面談ナビ_共有_2026」。
2. メニュー「拡張機能 → Apps Script」を開きます。最初からある `function myFunction() {…}` を消し、`Code.gs` の中身をまるごと貼り付けて、保存します。
3. スプレッドシートに戻って再読み込みすると、メニューに「三者面談ナビ」が出ます。
4. 「① 初期設定」を押します。初回は承認を求められます。「続行」→ 自分のアカウント →「詳細」→「（安全ではないページ）に移動」→「許可」と進み、もう一度押します。
   - 「面談記録」「使える先生」「コメント」シートができます。
   - 実行した八幡先生のアカウントが、管理者になります（「使える先生」に○付きで入ります）。
   - すでに前の版を入れていた場合も、Code.gs を貼り替えてから「① 初期設定」を押すと「使える先生」シートが増えます。
5. 「② 資料フォルダ（Googleドライブ）を設定する」を押し、2のフォルダのURLを貼り付けます。
6. 「③ アプリ（GitHub Pages）のURLを設定する」を押し、1の4のURLを貼り付けます。「アプリのURLを設定しました」と出れば完了です。


## 4. GASをウェブアプリとして公開する

1. Apps Scriptの右上「デプロイ → 新しいデプロイ」→ 歯車 →「ウェブアプリ」を選びます。
2. 次の2つを設定して「デプロイ」を押します。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**明星学苑内の全員**（学校のドメイン内の全員）
3. 表示された「ウェブアプリのURL」が、先生方が開くURLです。ブックマークしておきます。


## 5. 担任の先生に使ってもらう

1. 4のURLを担任の先生に伝えます。
2. 担任の先生が開くと「まだ使える先生に登録されていません」と出ます。お名前を入れて「利用を申請する」を押してもらいます。
3. 共有スプレッドシートの「使える先生」シートに、その先生のメールアドレスと名前が1行増えます。C列「許可」に **○** を入れます。
4. 1分ほどたってから、担任の先生に開き直してもらうと使えます。

申請してもらわずに、「使える先生」シートにメールアドレスを直接書いて○を入れてもかまいません。○を消すと使えなくなります。メニュー「使える先生を確認する」で、いま使える先生の一覧が見られます。

スプレッドシートを「リンクを知っている全員」やグループで共有しても、アプリは使える先生とみなしません。「使える先生」シートで○を付けてください。

生徒のアカウントから申請が来ることもあります。その行には○を付けないでください。


## 6. 資料を反映する（八幡先生：最初と、資料を入れ替えたとき）

1. 4のURLを開きます。
2. 右上「参考資料」→「Googleドライブの資料を読み込んで、みんなの画面に反映する」を押します。
3. 学籍番号・担任・男女・出身校などの列を除いてから共有スプレッドシートに保存し、学年の先生全員の画面に反映します。

管理者を増やすときは、メニュー「管理者を追加する」でメールアドレスを入れます。


## 7. 面談での使い方

1. 左の「① 条件を選ぶ」で、生徒・保護者に聞きながら条件を選びます。
   - 生徒メモ（任意）・希望進路・評定平均・7月模試GTZ・系統・受験方式（明星大学特別推薦を含む）・英語の資格
2. 右のタブで参考資料を見ます。
   - ② 模試ロードマップ
   - ③ 先輩の事例
   - ④ 複数プラン
   - ⑤ 指定校・Handy
   - ⑥ 面談シート
3. 見せるときは「生徒・保護者に見せる画面へ」を押します。教員用のヒントと面談記録が隠れます。
4. PDFにするときは、「面談シートをPDF・印刷」を押し、印刷画面で「PDFに保存」を選びます。
5. 面談が終わったら「次の生徒へ」を押します。


## 8. 記録と共有

1. 選んだ条件・志望校・検討候補・面談メモは、自動で記録されます。
2. 「⑦ 面談記録」に、すべての先生の記録が出ます。記録ごとのコメントと「学年全体への連絡」で、担任の先生と八幡先生が情報を共有できます。新しいコメントがあると「新着」と出ます。
3. 「続きを開く」で、記録の続きを書けます。担任名は、最初に記録した先生のまま変わりません。
4. 同じ内容が、共有スプレッドシートの「面談記録」「コメント」シートにも入ります。
5. 記録を削除できるのは、記録した本人と管理者だけです。


## アプリを直したとき

1. GitHubの `app.js`・`app.css` を差し替えます。先生方の画面には、1時間以内に反映されます。
2. `Code.gs` を直したときは、「デプロイ → デプロイを管理」→ 鉛筆マーク →「バージョン：新バージョン」→「デプロイ」で更新します。この方法ならURLは変わりません。


## うまく動かないとき

- 「まだ使える先生に登録されていません」と出る：その先生のメールアドレスの行が「使える先生」シートにあり、C列に○が入っているか確認します。○を入れたばかりのときは、1分ほどたってから開き直します。
- 表示されたアカウントが本人のものでない：その端末のSafari・Chromeが別のアカウントでログインしています。プライベートタブで、自分の学校アカウントだけでログインして開き直します。
- 「アプリのURLが未設定です」と出る：3の6を実行します。
- 画面が真っ白のまま：GitHub Pages に `app.js`・`app.css` があるか、3の6のURLが正しいかを確認します。
- 「ログインしているアカウントを確認できませんでした」と出る：学校のアカウントでログインしているか確認します。個人のGmailで開くと使えません。
- エラーの中身を知りたい：Apps Script左の「実行数」に、失敗の記録が出ます。


## 年度末・面談期間が終わったら

1. 「使える先生」シートの○を見直します。
2. 「面談記録」「コメント」シートは、学校のルールに従って保管または削除します。
